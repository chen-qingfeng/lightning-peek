# Security

Lightning Peek opens files from other people, so problems such as a crafted DWG/DXF that crashes the app, reads files it should not, or runs code are security issues.

**Please do not report security problems in public issues.** Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. If that button is not available, open an issue titled "Security contact request" without any details, and the maintainer will reply with a private channel.

Please include the version, what happens, and a minimal file or steps to reproduce. Fixes are released as a new version and noted in [CHANGELOG.md](CHANGELOG.md).

# 安全问题

闪电看图会打开别人发来的图纸，所以「特制的 DWG/DXF 能让程序崩溃、读取不该读的文件或执行代码」这类问题属于安全问题。

**请不要在公开 Issue 里报告安全问题。** 请用 GitHub 的私密漏洞报告：打开仓库的 **Security** 页，点 **Report a vulnerability**。如果没有这个按钮，请新建一个标题为「Security contact request」的 Issue，不写任何细节，维护者会回复私下联系方式。

请写明版本、现象，以及能复现问题的最小文件或步骤。修复会作为新版本发布，并记在 [CHANGELOG.md](CHANGELOG.md) 里。
