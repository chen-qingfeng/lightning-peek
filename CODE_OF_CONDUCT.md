# Code of conduct

Lightning Peek is built by people who read drawings for a living and people who write code. Please keep discussions useful for both.

- Be respectful. Disagree with ideas, not people. No harassment, insults, or discrimination of any kind.
- Stay on topic and assume good intent. Many contributors are not native English or Chinese speakers; either language is fine.
- Protect other people's data. Never post drawings, screenshots or file paths that contain someone else's client or personal information.
- Credit others' work, and only submit code you have the right to contribute under GPL-3.0-or-later.

The maintainer may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem privately, use the contact described in [SECURITY.md](SECURITY.md).

# 行为准则

闪电看图的参与者既有天天看图的工程人员，也有写代码的开发者，请让讨论对双方都有用。

- 互相尊重。可以反对观点，不攻击人；不骚扰、不辱骂、不歧视。
- 就事论事，先假定对方是善意的。中文、英文都可以。
- 保护别人的数据。不要发布含他人客户信息或个人信息的图纸、截图和文件路径。
- 尊重他人成果；只提交你有权按 GPL-3.0-or-later 贡献的代码。

维护者可以编辑或删除违反上述规则的评论、Issue 和 Pull Request，屡次违反的可以拉黑。需要私下反映问题，请按 [SECURITY.md](SECURITY.md) 里的方式联系。
